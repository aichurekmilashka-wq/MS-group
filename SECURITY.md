# Security Policy

## Supported Versions

Only the latest published version of this project receives security updates.

| Version | Supported |
|---------|-----------|
| Latest version | ✅ Yes |
| Older versions | ❌ No |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately using GitHub's "Report a vulnerability" feature, if available.

Please provide:
- A description of the issue.
- Steps to reproduce the vulnerability.
- The potential security impact.
- Screenshots or technical details, if available.

Please do not publicly disclose vulnerabilities before they are reviewed.

## Security Measures

This project follows basic security practices:

- API keys, passwords, and access tokens must not be stored in public source code.
- Dependencies should be kept up to date.
- Security issues should be reviewed and fixed according to their severity.
- Sensitive information must not be exposed through the website.

## Maintenance

The project is maintained by its owner.
Security reports are reviewed as time permits.
No guaranteed response time is provided.
