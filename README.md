# МСГ — многостраничный сайт

27 страниц: главная с Glyph Portal, общий каталог, 15 групп по предоставленному примеру, фасонный прокат, профильные трубы с ценами и три категории профиля, товар, корзина, кровельный калькулятор, контакты и оформление заказа.

Откройте index.html. Папка assets должна находиться рядом с HTML-файлами. Для GitHub Pages загрузите содержимое этой папки в корень репозитория, затем Settings → Pages → Deploy from a branch → main → / (root).

Цены даны для 178 позиций профильных труб по предоставленному прайсу; два нулевых значения показаны как «По запросу». В остальных разделах работает запрос спецификации и расчёта в WhatsApp. Цены кровли ожидают нового прайса. Наличие, оплату и получение подтверждает менеджер.

Проверены ссылки, модели расчёта и перенос корзины в симуляции DOM. Визуальную проверку в браузере в этом окружении выполнить не удалось.
